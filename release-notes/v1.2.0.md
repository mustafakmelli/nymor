# Nymor v1.2.0

Nymor v1.2.0 expands repo memory beyond static agent files. This release adds the first pieces of active codebase awareness: linting repository skills, mining code for rule candidates, and compiling more focused context for agent workflows.

## Highlights

- Added `nymor lint` to check code against enforceable skill patterns.
- Added `nymor mine` to discover potential repo rules from existing code.
- Added context-aware compilation paths for more focused agent guidance.
- Added MCP support so agents can query Nymor-managed repo memory directly.
- Improved generated agent surfaces for modern multi-agent workflows.

## Install

```sh
npm install -g nymor
```

Or run directly:

```sh
npx nymor init
```

## Verify

```sh
nymor --version
```
